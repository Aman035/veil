Watch your IP disappear

This page makes the same kind of read a dapp makes: a JSON-RPC request to a server that reports back the IP it saw. Done directly, the server sees your real IP. With Veil on, each of your accounts goes out on its own Tor circuit, so the server sees unrelated strangers, and never you.

Needs the Veil extension installed and on (and, on this build, your local gateway running). With Veil off or not installed, all three rows show the same real IP, that is the leak Veil removes. The reads go to a public IP echo (httpbin.org/anything); swap ECHO in this page for your own endpoint if you prefer. Addresses queried are still visible to providers by design; Veil removes your IP and the link between your accounts, not the addresses.  Back to Veil
